Why one picture mattersRAG isn't "LLM + Vector Search." It's Data Pipeline → RAG Chain → Evaluation → Governance — four layers, and each deck below is one of those layers zoomed in.
The one-line versionsAI Function = one batch operation. Agent = tools + retrieval + reasoning. Tracking = what happened. Registry = which version to deploy. Serving = how apps reach it.
