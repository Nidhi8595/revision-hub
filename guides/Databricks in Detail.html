🏥 PROJECT Healthcare Insights Platform 16 CARDS

MedCare — Healthcare Insights Platform

MedCare Regional Health Network stores clinical data in S3 and patient/billing data in Salesforce. The job: unify both in Databricks, produce trusted metrics, let patients query their own records in plain language, and give admins a dashboard — with real, enforced, role-based security throughout.

Why this is "substantially broader" than Lead Anomaly Detection

Same medallion skeleton, much more weight on top: two live source systems (not one), fine-grained security enforced at query time (not just table grants), a governed Vector Search + LLM Q&A layer for two very different audiences (patients vs admins), and a full dashboard — all under real PHI-grade governance requirements.
